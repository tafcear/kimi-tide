| 项 | 值 | 理由 |
|---|---|---|
| `activePreset` | `capability` | 先挂上路由（不设 = 路由关闭、评审流不挂载） |
| 省钱预设 | 默认 `deepseek-official/deepseek-flash`；规则：`image → zai-coding-cn/glm-5.3-flash`、`code → zai-coding-cn/glm-5.3` | 便宜模型干日常；带图必须有视觉目标（deepseek-flash 模态未知） |
| 能力预设 | 默认 `qwen-token-plan-cn/qwen3.8-max`；规则：`code → moonshotai-cn/kimi-k3` | 强模型干硬活；**故意不与 reviewer 同源**，否则评审退化成自评 |
| 评审流 | `reviewer: moonshotai-cn/kimi-k3`、`trigger: manual`、`rounds: 1`、`autoRevise: false`、`recheck: true` | 手动起步最省；回退开关留给用户在设置页开 |

| 关键词组 | 内置 7 组原样 | — |

**模型可用域**：目标只用了本 profile 已配的通道（`qwen-token-plan-cn` / `moonshotai-cn` / `zai-coding-cn` / `deepseek-official`）；插件对目录里不可用的目标自动跳过降级。

**生效方式**：宿主有 `app-boot/config-reload`（「Profile patches were reconciled into the running Loader tree」）⇒ patch 改动**热应用**，理论上不必重启；稳妥起见仍建议重启一次验证冷启动。

## 6. 口径修正（写给自己下次别再踩）

- 本仓 v1.3.1 的 peer 上界 `<0.2.0-0` 是**按当时宿主**钉的，不是"永久兼容"声明；桌面端升到 0.2.0-rc.2 后必须重开上界，否则 `plugin_manager` 会直接判不兼容、连装都不给装。
